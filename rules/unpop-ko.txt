! Clean room: every rule below was written from Unpop's own observation of live Korean mobile
! sites (requests WebKit sent, response types, and the page markup the request ended up in),
! loaded with an iPhone user agent in macOS WebKit on 2026-10-29. No rule was taken from, or
! checked against, List-KR, AdGuard or any other GPL filter list. Each group names the evidence.
!
! Policy: block the ad call, ad SDK or ad-only tracker, by host when every request observed on
! that host was ad delivery, otherwise by path. Never a content or image CDN wholesale
! (ssl.pstatic.net, *.daumcdn.net, *.kakaocdn.net serve real pages too; only their ad paths are
! listed). Ads that Naver's own search results render inline (Power Link, shopping ads) are not
! touched. Ad-click and ad-event hosts that a tapped ad link may pass through are blocked only as
! subresources ($~document), so a link the user chooses to open still works.
