오픈 소스 라이선스

Unpop의 차단 규칙은 아래 필터 목록으로 만들었어요. 만든 분들께 감사드려요.

규칙은 이 목록들을 Safari 형식으로 자동 변환한 것으로, 변환하면서 일부 규칙을 빼고 순서를 바꾸고 분량을 줄였어요. 변환된 규칙은 CC BY-SA 4.0 라이선스로 제공돼요.

변환된 규칙과 원본 목록

  • ads.json — Unpop Ads의 Safari 콘텐츠 차단 규칙 (8.0 MB)
  • privacy.json — Unpop Privacy의 Safari 콘텐츠 차단 규칙 (8.0 MB)
  • popup-hosts.json — Unpop 팝업 차단에 들어 있는 광고 호스트 목록 (67 KB)
  • unpop-ko.txt — Unpop 한국 광고 규칙, Unpop이 직접 만든 원본 목록 (5 KB)
  • acknowledgements.json — 아래 저작자 표시를 기계가 읽을 수 있는 형식으로
  • README — 라이선스, 변경 내용, 변환에 쓴 각 목록의 버전(영어)

아래 저작자를 밝히고, 변경했다는 사실을 표시하고, 고친 결과물을 같은 라이선스(CC BY-SA 4.0)로 공유하면 상업적 이용을 포함해 자유롭게 공유하고 고칠 수 있어요. hostsVN에서 온 부분에는 아래 MIT 고지도 함께 적용돼요.

Unpop 자체 코드

Unpop 앱과 확장 프로그램의 자체 코드는 이 페이지의 라이선스 대상이 아니에요. 이 라이선스들은 Unpop에 들어 있는 필터 데이터에 적용돼요. Unpop 팝업 차단에는 위에서 ‘Unpop 팝업 차단’에 쓰인 목록으로 만든 광고 호스트 목록(popup-hosts.json)이 들어 있어요. 목록 이름은 저작자를 밝히기 위해서만 쓰며, 목록 관리자들이 Unpop을 보증하는 것은 아니에요.
