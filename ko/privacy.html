개인정보 처리방침

시행일: 2026년 10월 28일

Unpop은 개인정보를 수집하지 않습니다. 계정, 분석 도구, 광고, Unpop 서버가 없으며, 웹 브라우징 정보는 기기 밖으로 나가지 않습니다.

기기에만 저장되는 정보

Unpop은 작동에 필요한 다음 정보만 iPhone 또는 iPad 안에 저장합니다.

  • 설정: 보호 켜기 여부, ‘광고 차단됨’ 알림 표시 여부 등
  • 횟수: 지금까지 막은 팝업 수, 오늘 사용한 무료 차단 횟수
  • 알림의 ‘허용’ 버튼으로 허용한 사이트
  • Unpop Pro 사용 여부

이 정보는 앱의 저장 공간과 Safari가 확장 프로그램에 제공하는 저장 공간에만 보관되며, 개발자를 포함한 누구에게도 전송되지 않습니다. Unpop을 삭제하면 함께 삭제됩니다. 다른 앱 데이터와 마찬가지로 기기 백업에 포함될 수 있으며, 백업은 Apple의 개인정보 처리방침에 따라 관리됩니다.

Safari 확장 프로그램

Unpop Ads와 Unpop Privacy는 콘텐츠 차단기입니다. 앱에 포함된 차단 규칙을 Safari에 전달할 뿐이며, 규칙은 Safari가 직접 적용합니다. 콘텐츠 차단기는 이용자가 방문하는 페이지를 볼 수 없습니다.

Unpop 팝업 차단은 Safari 웹 확장 프로그램입니다. 광고 팝업과 이용자가 직접 연 팝업을 구별하려면 방문한 페이지에서 작동해야 하므로, Safari가 웹사이트 접근 허용을 요청합니다. 모든 판단은 기기 안에서 이루어지며, 방문한 페이지의 주소나 내용을 기록·저장·전송하지 않습니다. 같은 기기의 Unpop 앱에 전달하는 정보는 막은 팝업의 수뿐이며, 허용한 사이트는 기기 안의 Safari 저장 공간에 보관합니다.

차단 규칙은 앱에 포함되어 앱 업데이트와 함께 갱신됩니다. Unpop은 웹 브라우징 중에 필터 목록을 내려받거나 서버에 접속하지 않습니다.

구매

Unpop Pro는 App Store를 통해 판매되며 결제는 Apple이 처리합니다. 개발자는 결제 정보, 이름, 이메일 주소를 받지 않습니다. 앱은 기기에서 Apple에 Unpop Pro 구매 여부만 확인합니다. 자세한 내용은 Apple 개인정보 처리방침을 참고하세요.

진단 정보

Unpop에는 자체 분석·오류 보고 기능이나 외부 SDK가 없습니다. iOS의 설정 › 개인정보 보호 및 보안 › 분석 및 향상에서 앱 개발자와 공유를 켠 경우, Apple이 개인을 식별할 수 없는 형태의 오류 보고서와 사용 통계를 개발자와 공유할 수 있습니다. 이는 Apple이 관리하며 언제든 끌 수 있습니다.

문의할 때 받는 정보

이메일이나 GitHub 이슈로 문의하면 보내 주신 내용(예: 이메일 주소)을 받게 되며, 답변에만 사용하고 그에 필요한 기간 동안만 보관합니다. GitHub 이슈는 누구나 볼 수 있습니다.

이 웹사이트

이 웹사이트는 GitHub Pages에서 제공하는 정적 페이지입니다. 쿠키, 분석 도구, 추적기를 쓰지 않으며 다른 사이트의 파일을 불러오지 않습니다. 호스팅 업체인 GitHub는 서비스 운영과 보안을 위해 IP 주소 같은 기술 정보를 기록할 수 있습니다(GitHub 개인정보처리방침).

아동

Unpop은 아동을 포함한 누구의 개인정보도 수집하지 않습니다.

이용자의 선택

개발자는 이용자의 개인정보를 보유하지 않으므로 열람하거나 삭제할 정보가 없습니다. Unpop이 기기에 저장한 정보를 모두 지우려면 앱을 삭제하세요. Safari 확장 프로그램은 언제든 설정 › 앱 › Safari › 확장 프로그램에서 끌 수 있습니다. 개인정보를 제3자에게 제공하거나 처리를 위탁하지 않습니다.
